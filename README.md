# GhosterAI 3.3.5 — локальная сборка для Windows x64

Публичная сборка GhosterAI без встроенных API-ключей и без облачного аккаунта.
Приложение работает локально: настройки, история и ключи хранятся в профиле
WebView2 на вашем компьютере. Запросы к моделям уходят напрямую выбранному
провайдеру с вашим ключом.

## Что внутри

- Настоящий установщик Windows (Inno Setup) и portable ZIP.
- Никаких ключей, токенов и секретов в exe, установщике или архиве.
- Мультиключи: можно добавить несколько ключей одному провайдеру; при ошибке
  401/403/404 приложение переключается на следующий ключ.
- Около 30 готовых провайдеров: OpenAI, Google Gemini, OpenRouter, DeepSeek,
  Groq, Mistral, xAI, Together, Perplexity, Fireworks, Cohere, Cerebras,
  SambaNova, Nebius, Hyperbolic, Novita, DeepInfra, Lambda, Moonshot, Zhipu,
  Alibaba Qwen, Baidu Qianfan, SiliconFlow и другие.
- Локальные OpenAI-совместимые серверы: Ollama, LM Studio, vLLM (включаются
  отдельным чекбоксом «использовать локальный сервер»).
- Свой OpenAI-совместимый провайдер: произвольный URL и модели.
- Озвучка: ElevenLabs и Fish Audio (только TTS, не участвуют в чате).
- Потоковые ответы, изоляция сессий, сохранение истории в localStorage.
- FFmpeg для обработки аудио (GPLv3, см. `NOTICE` и
  `FFMPEG_SOURCE_OFFER.md`).

## Установка

### Установщик

Запустите `GhosterAI-3.3.5-win64-setup.exe` и следуйте мастеру. Установщик
ставит приложение для текущего пользователя (без прав администратора) и
создаёт ярлыки в меню «Пуск» и на рабочем столе.

### Portable

Распакуйте `GhosterAI-3.3.5-win64-portable.zip` в любую папку и запустите
`GhosterAI.exe`. Папку `ffmpeg` нельзя удалять: она нужна для обработки аудио.

Требования: Windows 10/11 x64, WebView2 Runtime (в Windows 11 обычно уже
установлен; если приложение не запускается, установите Evergreen WebView2
Runtime с сайта Microsoft).

## Первый запуск

1. Пройдите короткий онбординг (звук, режим записи, вид чата).
2. Нажмите кнопку **API** в правом нижнем углу.
3. Добавьте ключ хотя бы одного провайдера. Для локального сервера включите
   чекбокс «использовать локальный сервер» и укажите URL.
4. Нажмите **Сохранить и перезапустить**.
5. Создайте встречу и выберите модель в селекторе.

Ключи можно не добавлять заранее: приложение подскажет это баннером, но не
отправит вас на регистрацию или облачный аккаунт.

## Безопасность и приватность

- Ключи хранятся **в открытом виде** в `localStorage` профиля WebView2. Это
  видимое предупреждение показывается в окне ключей. Используйте отдельный
  профиль Windows и не запускайте приложение на общем компьютере.
- Нет Supabase, Sentry, аккаунта Ghoster и облачной синхронизации.
- Нет встроенных ключей и прокси-сервера. Поле HTTP-прокси по умолчанию пустое.
- Запросы идут напрямую к API выбранного провайдера. Если провайдер
  недоступен, приложение покажет ошибку, а не будет молча отправлять данные
  на сторонний сервер.
- История чата сохраняется локально в `localStorage["ghoster_messages"]` и
  привязана к встрече и подчату.

Подробнее о ключах: [`docs/API_KEYS.ru.md`](docs/API_KEYS.ru.md).

## Сборка

В репозитории лежат:

- `src/key-manager.js` — менеджер ключей и локальный мост истории;
- `src/web-dist/` — очищенные веб-ассеты; они генерируются скриптом
  `sanitize_assets.py` из исходных ассетов и не входят в git из-за
  происхождения и размера;
- `scripts/sanitize_assets.py` — очистка исходных ассетов от ключей и
  облачных хостов;
- `scripts/inject_assets.py` — упаковка ассетов в Brotli/PHF-таблицу
  исполняемого файла;
- `scripts/scan_release.py` — проверка релиза на секреты и запрещённые хосты;
- `installer/GhosterAI.iss` — сценарий Inno Setup.

Скрипты и документация распространяются по MIT (`LICENSE`). Сам бинарник —
freeware/proprietary (`LICENSE-APP`). Исходный код upstream-приложения и
оригинальные веб-ассеты с секретами в репозиторий не входят. Для повторной
сборки нужен чистый upstream-бинарник и исходные ассеты, которых нет в
публичном репозитории; публичная сборка воспроизводится из уже очищенных
ассетов и скриптов.
